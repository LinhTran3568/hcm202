# Phiên tòa gia đình giả định (HCM 202)

Trang thuyết trình học thuật dạng web tương tác cho môn Hồ Chí Minh: một phiên tòa gia đình giả định với các phần nhân vật, tranh luận, thẩm phán tổng kết, liên hệ tư tưởng Hồ Chí Minh, tương tác với lớp và kết luận.

## Chạy dự án

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Cấu trúc

- `src/data/script.js` — nội dung kịch bản phiên tòa (sửa nhóm, đối thoại ở đây)
- `src/components/` — các section của trang
- `src/styles.css` — toàn bộ style
- `scripts/check.mjs` — script kiểm tra tự động (QA)
